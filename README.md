# Sneha Agrawal — Portfolio

Modern, pastel-themed portfolio showcasing full-stack development, design systems, and creative engineering.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## 📬 Contact Form Setup (Formspree)

Contact form submissions are sent to `snehha.ag2610@gmail.com`.

To receive real email notifications:
1. Create a free form at [Formspree](https://formspree.io/) set to forward to `snehha.ag2610@gmail.com`.
2. Copy your form ID (e.g. `xpzgabxy`).
3. Create a `.env.local` file in the root directory:
   ```env
   NEXT_PUBLIC_FORMSPREE_KEY=your_form_id_here
   ```
4. Restart your development server. Submissions will directly land in your inbox!
